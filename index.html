ARRIVA هو منبه ذكي يعتمد على تحديد المواقع GPS وخرائط جوجل. يوقظك تلقائياً قبل الوصول إلى محطتك أثناء التنقل بالحافلة أو القطار.

📱 تحويل إلى تطبيق APK
  1. PWA : افتح الموقع في متصفح الهاتف ← قائمة ⋮ ← «إضافة إلى الشاشة الرئيسية».
  2. Capacitor : npm i @capacitor/core @capacitor/android ثم npx cap add android وأخيراً ./gradlew assembleDebug.
  3. Bubblewrap (TWA) : npx @bubblewrap/cli init --manifest=https://votre-site/manifest.json ثم build.
  4. Cordova : cordova create arriva ثم cordova platform add android و cordova build android.
